身份证件与驾照

在美国办事到处要出示带照片的证件。不开车的人可以只办一张身份证。

一、两种证件

中文英文说明
州身份证State ID 不开车的人办这个，只用来证明身份
驾照Driver's License 能开车，也能当身份证用

两种都在车管所办，英文叫 DMV（Department of Motor Vehicles） 。

二、在 DMV 怎么说

中文英文
我要办一张州身份证I'd like to apply for a state ID.
我要考驾照I'd like to apply for a driver's license.
笔试有中文的吗Is the written test available in Chinese?
我预约了I have an appointment.
我需要中文翻译I need a Chinese interpreter.
我还缺什么材料What documents am I missing?
什么时候能拿到When will I receive it?

💡 多数州的驾照笔试有中文版

不少州的笔试可以选中文，甚至有中文语音。具体哪些州、哪些语言，以您所在州 DMV 官网为准。
